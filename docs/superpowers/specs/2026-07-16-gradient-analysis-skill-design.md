## 一、背景与动机

### 1.1 触发事件

DeerFlow 对"宝应→高邮段为何是全线最陡梯度段"的回答中，豆包评审发现以下问题：

- **硬错误 1**：将"总落差最大"（0.06m，因为河段最长 52km）等同于"比降最陡"，混淆了概念
- **硬错误 2**：正负号方向约定未显式说明，导致顺坡/逆坡混用
- **硬错误 3**：用经纬度直线距离替代实际河长，未标注精度误差
- **深层不足**：缺乏湖泊调蓄两模式分拆、泵站与湖泊的"双向力"分析、多站归因排除等框架

### 1.2 当前技能覆盖状态

| 维度 | 当前状态 |
|------|---------|
| 水位查询 | ✅ 完善 |
| 超警戒判断 | ✅ 完善（含阈值验证） |
| 统计对比 | ✅ 完善（含口径说明） |
| 水体分类 | ✅ 完善（reference 文档） |
| 高程基准 | ✅ 完善（reference 文档） |
| **梯度分析（比降/倒挂/坡度）** | ❌ **完全缺失** |
| 人工调度影响分析 | ❌ 缺失 |
| 湖泊调蓄对河道梯度的影响 | ❌ 缺失 |

### 1.3 设计目标

补充水文梯度分析的全套能力，使 LLM 在遇到"最陡""坡度""比降""倒挂""梯度"等场景时：

1. 能正确区分总落差 vs 水力比降
2. 能正确计算并标注比降（含精度说明）
3. 能识别逆梯度（水位倒挂）并归类成因
4. 能进行多站对比 + 归因排除分析
5. 能在报告中正确标注方向约定、里程精度、时间段

## 三、详细设计

### 3.1 `references/gradient_analysis.md` 文档结构

```
§1 基本概念与口径约定
  1.1 总落差（Total Drop）— 定义、公式、适用场景
  1.2 水力比降/纵比降（Gradient）— 公式 J = Δz/L、口径说明
  1.3 核心区别：总落差大 ≠ 比降陡（含数值示例）
  1.4 方向约定：顺坡/逆坡、正负号含义

§2 计算精度说明
  2.1 河段长度三种获取方式及优先级
  2.2 直线距离估算的标注要求

§3 水位逆梯度（倒挂）分析
  3.1 判定条件
  3.2 三种典型成因框架（湖泊顶托型 / 泵站抽水型 / 潮汐顶托型）
  3.3 各时段特征对比（平水/调水/汛期/枯水）

§4 多站梯度对比分析框架
  4.1 标准步骤（6步）
  4.2 归因排除法（排除其他河段不具备的条件）
  4.3 平水期 vs 调度期对比表

§5 湖泊调蓄对河道梯度影响（扬州地区）
  5.1 高邮湖（面积750km²，调蓄两模式）
  5.2 邵伯湖（面积77km²，顶托有限）
  5.3 洪泽湖（上游，暂不展开）

§6 人工调度对水位梯度的影响
  6.1 泵站集群效应（上行抽空 + 下行顶托 = 双向力）
  6.2 闸门调控（短期局部，非核心）
  6.3 天然水文 vs 人工调度分离分析

§7 典型分析案例（宝应→高邮）
  完整6步分析演示

§8 输出规范
  8.1 数据标注要求
  8.2 局限性说明

§9 更新日志
```

### 3.2 Pitfalls 新增内容（3条）

```
1. 总落差 ≠ 水力比降（高频概念混淆）
2. 直线距离 ≠ 河道实际里程
3. 水位梯度方向需显式约定（高频遗漏）
```

详见模板草稿中的配套措辞。

### 3.3 Workflow 新增 Step 12

```markdown
12. **[可选] 梯度分析（多站水位对比场景）**
    当用户问题涉及"最陡"、"坡度"、"梯度"、"倒挂"、"比降"，
    或对比 ≥2 站水位落差时：
    a) 判断是否需要梯度分析 → 是则引用 references/gradient_analysis.md
    b) 按 §2 获取河段长度（实测里程优先，直线距离需标注精度）
    c) 计算比降：Δz / L，区分总落差 vs 单位比降
    d) 标注方向约定（以常年自然流向为正方向）
    e) 判断是否存在逆梯度（水位倒挂），按 §3 归类成因类型
    f) 如有 ≥3 站，按 §4 做多站对比 + 归因排除分析
    g) 输出时标注：里程精度、方向约定、时间段（平水/调度/汛期）
```

### 3.4 Validation Gate 新增（2项）

在"统计口径说明"之后、"数值合理性检查"之前插入：

```
### 坡度计算口径检查（新增，多站梯度对比场景）
- [ ] 比降已按单位里程计算，而非仅列总水位差
- [ ] 河段长度来源已标注（实测/核定/直线距离⚠️）
- [ ] 方向约定已说明（正方向定义、正负号含义）
- [ ] 时间段已区分（平水/调水/汛期）
- [ ] 排除分析已完成（≥3站时）

### 数据局限性说明（新增）
- [ ] 精度局限性（直线距离估算时已标注⚠️）
- [ ] 时段局限性（不可外推时已说明）
- [ ] 人工调度影响（非自然水位时已说明）
```
