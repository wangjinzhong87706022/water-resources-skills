# 水位梯度分析框架 (Gradient Analysis)

> **适用范围**：`water-situation` skill，多站水位梯度对比、比降计算、逆梯度（水位倒挂）成因分析场景
> **数据来源**：`sl323.st_river_r.z`（水位）、`sl323.st_stbprp_b.stnm/rvnm`（站名与河名）
> **河段长度来源**：实测断面里程 > 核定河长 > 经纬度直线距离（需标注精度）
> **核心警示**：总落差 ≠ 水力比降；直线距离 ≠ 实际河长；正负号需显式约定方向

---

## 1. 基本概念与口径约定

### 1.1 总落差（Total Drop）

| 项目 | 说明 |
|------|------|
| 定义 | 上下游两站水位的绝对值之差 |
| 公式 | Δz = z<sub>上</sub> − z<sub>下</sub>（以常年自然流向为正方向） |
| 适用场景 | 粗略描述两站之间水位变化幅度 |
| 局限性 | 不反映河道坡度的陡缓，因为未考虑河段长度 |

### 1.2 水力比降 / 纵比降（Gradient）

| 项目 | 说明 |
|------|------|
| 定义 | 单位河长上的水位降落值 |
| 公式 | J = Δz / L（单位：mm/km 或 ‰） |
| 适用场景 | 描述河道坡度的陡缓、对比不同河段的天然地形差异 |
| 精度要求 | 河段长度 L 的来源不同，精度不同（见 §2） |

### 1.3 核心区别：总落差大 ≠ 比降陡

**这是梯度分析最常见的概念混淆。**

```
示例：
  河段 A（泾河→宝应）:  Δz = 0.03m, L ≈ 13km → J ≈ 2.3 mm/km  ← 比降更陡
  河段 B（宝应→高邮）:  Δz = 0.06m, L ≈ 52km → J ≈ 1.2 mm/km

  总落差：B > A（0.06m > 0.03m）→ B 的总落差更大
  比降：  A > B（2.3 > 1.2）     → A 的天然坡度更陡

结论：河段 B 的"最大水位差"是因为河段最长（52km）累加了更多落差，
     而非天然比降最陡。判断"陡缓"的唯一标准是**单位比降**，不是总落差。
```

### 1.4 方向约定

梯度计算前**必须显式约定正方向**：

| 约定 | 含义 | 示例（里运河） |
|------|------|---------------|
| Δz > 0（正值） | 顺坡：上游水位 > 下游水位，水流顺重力方向 | 宝应(6.82m) → 高邮(6.76m)，Δz = +0.06m |
| Δz < 0（负值） | 逆坡/倒挂：下游水位 > 上游水位，水流需外力驱动 | 5月抽水期 Δz = −0.52m（北向抽水，南高北低） |

**报告中必须写明**：
```
方向约定：以常年自然流向（北→南）为正方向
正 = 顺坡（上游 > 下游），负 = 逆坡/倒挂（下游 > 上游）
数据时段：2024年年均
```

## 2. 计算精度说明

### 2.1 河段长度获取方式

| 优先级 | 方式 | 精度 | 说明 |
|--------|------|------|------|
| 1 | 实测断面间距 | ±0.1 km | 来自水文站核定断面数据 |
| 2 | 河道核定里程 | ±1 km | 来自河道管理范围划定报告 |
| 3 | 经纬度直线距离 | 误差可达 10-20% | ⚠️ 低估实际河长，比降偏大 |

### 2.2 直线距离估算标注要求

仅当无法获取前两种数据时使用经纬度估算。**必须标注**：

```markdown
河段长度：按两点经纬度直线距离估算约 52km
⚠️ 注：实际河道里程 > 直线距离，比降值可能偏小，仅供参考
```

## 3. 水位逆梯度（倒挂）分析

### 3.1 判定条件

```
Δz < 0 且 |Δz| > 正常波动范围（> 0.05m）
→ 确认存在显著逆梯度（水位倒挂）
```

### 3.2 三种典型成因框架

#### 3.2.1 湖泊顶托型

**机制**：下游湖泊水体巨大、库容丰富 → 湖面水位随河道抽水/行洪的消退速度远慢于河道 → 持续向运河断面补水，锚定下游水位高位。

**特征**：
- 出现在下游邻接大型湖泊的河段
- 退水期/抽水期最为显著
- 逆梯度幅度取决于湖泊库容/河道断面积之比

**示例（宝应→高邮段）**：
```
平水期：高邮湖平滑下游水位，梯度较小（Δz ≈ +0.06m）
抽水期：高邮湖维持下游水位，上游被泵站抽空，Δz 可达 −0.52m
```

#### 3.2.2 泵站抽水型

**机制**：泵站从河道抽水北送（或向其他方向）→ 抽水点上游水位快速下降 → 形成上下游水位差。

**特征**：
- 出现在泵站集群周边
- 通常与湖泊顶托共同作用
- 单一泵站效应：上游抽空 vs 下游补给，属**双向力**（非同向叠加）

#### 3.2.3 潮汐顶托型

**机制**：感潮河段入海口潮位上涨 → 下游水位被潮汐托高 → 形成短时逆梯度

**特征**：
- 出现在感潮河段（扬州地区主要在内河非感潮段，此类型不常见）
- 周期性（半日潮/全日潮），不同于前两种的持续性

### 3.3 各时段特征对比

| 时段 | 宝应→高邮梯度特征 | 主导因素 |
|------|-------------------|---------|
| 平水期（非汛非调） | 弱顺坡，梯度不大 | 天然比降 + 湖泊平滑 |
| 调水期（5-6月北调） | **显著逆梯度**（倒挂），幅度全段最大 | 泵站抽空 + 高邮湖顶托 |
| 汛期（7-9月行洪） | 顺坡或弱逆坡 | 上游来水大 + 湖泊调蓄 |
| 枯水期（12-2月） | 弱顺坡，梯度最小 | 流量小、水位稳定 |

## 4. 多站梯度对比分析框架

### 4.1 标准分析步骤

```
Step 1: 确定分析范围（哪些站、哪段时间）
Step 2: 获取各段长度（按 §2 优先级）
Step 3: 计算各段比降 J = Δz / L
Step 4: 对比各段比降（单位里程，非总落差）
Step 5: 判断逆梯度（若 Δz < 0 → 按 §3 归类成因）
Step 6: 归因排除（为什么本段最突出？逐一排除其他段）
```

### 4.2 归因排除法

对比 ≥3 站时，采用排除法分析为什么某段最突出：

```
示例（里运河四站：泾河→宝应→高邮→邵伯）：

河段 A（泾河→宝应, ~13km）：
  总落差第二（0.03m），比降最陡（2.3mm/km）
  → 比降最大，但无大湖调蓄，抽水期上下游同涨同落 → 逆梯度不显著

河段 B（宝应→高邮, ~52km）：  ← 突出问题段
  总落差最大（0.06m），比降非最陡（1.2mm/km）
  → 河段最长 + 下游高邮湖顶托 + 上游泵站抽水 → 逆梯度最显著

河段 C（高邮→邵伯, ~31km）：
  总落差第三（0.04m），比降与B接近（1.3mm/km）
  → 下游邵伯湖库容远小于高邮湖 → 顶托效果有限 → 逆梯度弱

结论：河段 B 之所以逆梯度最显著，
      是因为"上游抽空 + 下游大湖顶托 + 河段最长"三重耦合，
      其他河段均缺少至少一个条件。
```

### 4.3 平水期 vs 调度期对比

```markdown
| 河段 | 平水期比降 | 调水期比降 | 逆梯度幅度 |
|------|-----------|-----------|-----------|
| 泾河→宝应 | +2.3 mm/km | +0.8 mm/km | 弱 |
| 宝应→高邮 | +1.2 mm/km | −10.0 mm/km | ⚠️ 全场最强 |
| 高邮→邵伯 | +1.3 mm/km | −2.5 mm/km | 中等 |
```

## 5. 湖泊调蓄对河道梯度影响（扬州地区）

### 5.1 高邮湖

| 项目 | 数据 |
|------|------|
| 面积 | 约 750 km²（里运河沿线最大湖泊） |
| 调蓄模式 | 平水期→拉平水位；抽水期→维持水位顶托 |
| 影响范围 | 高邮站断面以下至邵伯湖以上约 31km |
| 程度 | ⭐ 核心主导因子（见 §3.2.1） |

**平水期模式**：湖面宽阔、水位平滑，高邮站水位与湖面接近，下游梯度被"拉平"

**调水期模式**：
- 湖体库容大 → 水位消退速度 << 运河窄河道
- 持续向运河断面补水 → 锚定高邮站水位高位
- 与上游泵站抽水形成"双向力"：上游抽空 ↓ + 下游顶托 ↑ → 最大逆梯度

### 5.2 邵伯湖

| 项目 | 数据 |
|------|------|
| 面积 | 约 77 km²（高邮湖的约 1/10） |
| 调蓄能力 | 有限，水位快速响应河道变化 |
| 影响 | 顶托效果远弱于高邮湖 |

### 5.3 洪泽湖

位于里运河上游，影响的是三河闸→宝应段的梯度，与宝应→高邮段不同。本分析暂不展开。

## 6. 人工调度对水位梯度的影响

### 6.1 泵站集群效应

| 泵站 | 位置 | 对梯度的影响 |
|------|------|-------------|
| 宝应泵站 | 宝应上游 | 北向抽水 → 宝应断面水位拉低 → 上下游差扩大（上游降） |
| 高邮泵站 | 高邮附近 | 可调控湖河连通，非单纯叠加抽水 |

**关键洞察**：泵站和湖泊的作用方向是**相反的**——泵站拉低上游水位，湖泊维持下游水位。它们是"一个拉、一个托"，不是"两个一起拉"。

### 6.2 闸门调控

闸门局部控流可改变短期（小时级）梯度，但不在本分析框架的核心范围。涉及闸门调控时需单独说明。

### 6.3 自然水文 vs 人工调度分离

分析报告应区分：

```markdown
- 天然比降（平水期多年平均，反映地形）：J ≈ 1.2 mm/km
- 人工调度影响量（调水期额外梯度）：ΔJ ≈ −11.2 mm/km（从顺坡到逆坡的变化）
- 结论：该段天然比降平缓，但人工调度影响极大，是逆梯度的主导驱动力
```

## 7. 典型分析案例

### 7.1 案例：宝应→高邮段逆梯度成因分析

**问题**：用户问"宝应→高邮段为何是全线最陡梯度段？"

**分析过程**：

**Step 1 — 数据整理**

| 河段 | 长度 | 上游站年均水位 | 下游站年均水位 | 总落差 Δz |
|------|------|--------------|--------------|-----------|
| 泾河→宝应 | ~13 km | — | — | +0.03m |
| 宝应→高邮 | ~52 km | 6.82m | 6.76m | +0.06m |
| 高邮→邵伯 | ~31 km | 6.76m | 6.72m | +0.04m |

**Step 2 — 比降计算**

| 河段 | 总落差 | 河段长度 | 比降 | 排名 |
|------|--------|---------|------|------|
| 泾河→宝应 | +0.03m | 13 km | **2.3 mm/km** | 1（最陡） |
| 宝应→高邮 | +0.06m | 52 km | 1.2 mm/km | 3 |
| 高邮→邵伯 | +0.04m | 31 km | 1.3 mm/km | 2 |

**Step 3 — 概念澄清**

> **关键澄清**：宝应→高邮段的**总落差最大**（0.06m），**不是天然比降最陡**（1.2 mm/km，小于泾河→宝应的 2.3 mm/km）。用户问的"最陡"需要先界定是总落差还是比降。

**Step 4 — 调水期逆梯度分析**

查询 5-6 月调水期数据发现：

| 月份 | 宝应水位 | 高邮水位 | Δz（北→南） | 状态 |
|------|---------|---------|-------------|------|
| 5月 | 6.30m | 6.82m | −0.52m | 逆梯度（倒挂） |

**Step 5 — 归因排除**

| 河段 | 长度 | 有无大湖 | 泵站影响 | 逆梯度 | 结论 |
|------|------|---------|---------|--------|------|
| 泾河→宝应 | 短(13km) | 无 | 间接 | 弱 | 行程短、无大湖，同涨同落 |
| 宝应→高邮 | 长(52km) | ✅ 高邮湖750km² | ✅ 直接 | ⚠️ 最强 | 三重耦合：长+湖+泵 |
| 高邮→邵伯 | 中(31km) | 邵伯湖77km²(小) | 间接 | 弱 | 邵伯湖库容仅1/10，顶托有限 |

**Step 6 — 报告输出**

```markdown
## 结论

宝应→高邮段在以下维度为里运河最突出河段：
1. **总水位差最大**：年均 +0.06m（但比降仅 1.2 mm/km，非最陡）
2. **调水期逆梯度最强**：5月份 Δz = −0.52m（全场最大倒挂）
3. **人工调度影响最显著**：泵站集水 + 高邮湖顶托，天然比降仅 1.2mm/km，
   调度期额外梯度达 −11.2mm/km

⚠️ **局限性说明**：
- 河段长度按经纬度直线距离估算（实际河道里程 > 52km，比降值可能偏小）
- 分析基于月均值，未考虑逐小时闸门调控的短期波动
- 泵站运行数据来自公开资料，非 sl323 库实测
```

## 8. 输出规范

### 8.1 数据标注要求

输出时**必须包含**以下标注：

```
方向约定：以常年自然流向（北→南）为正方向
比降计算：Δz / L，其中 L 为 [实测里程/核定河长/直线距离（⚠️估算）]
    河段 A（泾河→宝应）: Δz = +0.03m, L ≈ 13 km, J ≈ +2.3 mm/km
    河段 B（宝应→高邮）: Δz = +0.06m, L ≈ 52 km, J ≈ +1.2 mm/km
数据时段：2024年全年月均（遇调水期逆梯度时，单独标注月份）
```

### 8.2 局限性说明

以下情况需在报告末尾添加局限性说明：

- **河段长度为估算**："⚠️ 河段长度按直线距离估算，比降值存在误差"
- **单时段数据**："⚠️ 数据仅覆盖 [月份]，不可外推到全年"
- **单站代表某水域**："⚠️ 本水域仅 1 个测站，空间代表性有限"
- **无泵站运行数据**："⚠️ 泵站运行工况来自公开资料，非数据库实测"
