## 6. ⚠️ 核心异常:`sql_generated = 0`(68/68)

**现象**:全部 68 条记录 `actual_sqls` 为空、`sql_generated=0.0`,因此 `sql_replay_ok` 连锁为 0,总分被压在 ~0.2。`has_valid_response≈1` 说明 **gateway 平台本身在线、有返回**,问题出在「SQL 没被抓到 / 没被生成」。

**两种可能(待定性)**:
1. **评分器抽取错位(artifacts,可能性高)**:`run_one_case` 解析 gateway 返回的结构里没有匹配到 SQL 字段 —— agent 其实生成了 SQL,只是没被 `actual_sqls` 捕获。100% 命中而非零星,倾向此解释(也吻合历史记忆 *eval-replay 抓 SQL 有假阴性*)。
2. **agent 真回归**:DeerFlow agent 这一轮确实没产出可执行 SQL。

**定性方法(一次调用)**:取某题的原始 gateway 返回,看响应体里到底有没有 SQL —— 有则是 #1,无则是 #2。在重跑全量(约 5.5h)前强烈建议先做这一步。
